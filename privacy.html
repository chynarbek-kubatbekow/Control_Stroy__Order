Политика конфиденциальности

Основные положения об использовании данных, которые посетитель добровольно передаёт для обратной связи.

Настоящая страница описывает общий порядок обработки данных, которые пользователь добровольно указывает для связи с Control Stroy.

Какие данные используются

Имя, номер телефона и сведения о предполагаемом объекте, указанные пользователем в форме.

Цель обработки

Данные используются для ответа на обращение и предварительного обсуждения услуг. Сайт не отправляет форму на собственный сервер: после проверки полей браузер формирует сообщение и открывает WhatsApp.

Передача через WhatsApp

При переходе пользователь взаимодействует с сервисом WhatsApp, обработка данных в котором регулируется условиями этого сервиса. Сообщение отправляется только после действия пользователя.
